Como se cadastrar no Painel de Gravação

O cadastro gratuito dá acesso à área do cliente para escolher locutores, adquirir créditos e solicitar gravações. Primeiro você cria o acesso; depois completa os dados cadastrais para utilizar a compra automática de créditos.

Atualizado em 03 de outubro de 2026 · Equipe A Locução

Antes de começar

Tenha um e-mail que você acessa e seu telefone atual. Criar a conta não compra créditos nem envia um pedido de gravação.

Passo a passo

PASSO 01

Abra a página de cadastro

Acesse Fazer pedido pelo WhatsApp. O formulário do Painel de Gravação aparece dentro do site da A Locução. Se você já tem acesso, use Fazer pedido pelo WhatsApp em vez de criar outra conta.

PASSO 02

Preencha os dados de acesso

Informe seu nome, seu melhor e-mail e telefone. Preencha também os campos de usuário e senha apresentados no formulário. Use uma senha exclusiva e guarde-a com segurança. Revise a digitação do e-mail para conseguir receber comunicações do pedido.

PASSO 03

Leia os termos e crie sua conta

Leia os Termos de Uso e a Política de Privacidade disponíveis no cadastro. Confira os dados e, se concordar com as condições, clique em Criar conta grátis. Caso o painel informe que o usuário ou e-mail já existe, tente entrar com o acesso anterior.

PASSO 04

Entre e complete o cadastro

Depois da criação, acesse Fazer pedido pelo WhatsApp com seu usuário ou e-mail e senha. Abra o menu do perfil, entre em Minha conta e complete os dados cadastrais. Essa etapa é necessária antes de adquirir créditos automaticamente.

Qual é o próximo passo?

Siga o tutorial para completar o cadastro. Depois, escolha entre Locução Off, para receber somente a voz, e Produção de Spot, para receber o anúncio com trilha, efeitos e finalização.

Perguntas frequentes

O cadastro é gratuito?

Sim. Criar a conta é gratuito. As gravações são solicitadas com créditos do serviço escolhido.

Criar a conta já libera a compra automática?

Você também precisa completar os dados cadastrais em Minha conta. O formulário inicial cria o acesso; o cadastro completo permite adquirir créditos de forma automática.

Posso me cadastrar pelo celular?

Sim. Abra a página de cadastro no navegador do celular e preencha o formulário. Se algum campo não aparecer, role a área do painel.
